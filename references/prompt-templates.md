# 完整提示词模板

以下两套提示词可直接粘贴到 GPT-Image2、ChatGPT 等图像生成工具中使用。

## 使用方式

1. 将完整提示词粘贴到对话框，先生成一张
2. 后续只需输入「目标文字」即可，无需重贴整个提示词
3. 如需指定比例：输入「目标文字，3:4」
4. 提示词遵循出现问题后，新开对话继续

## 模板 A：作者版（约 5000 字）

侧重字体设计感的深度约束，14 条规则覆盖从语义理解到画面完成度。

```
请以「[目标字词]」为核心，生成一张顶级字体美学概念图像。这张图像的首要任务不是做一个漂亮背景，也不是做一个普通艺术海报，而是让「[目标字词]」成为画面中最强、最大、最醒目、最有记忆点的视觉主体。「[目标字词]」必须在第一眼被看到、被读懂、被感受到。文字必须拥有压倒性的主视觉权重，占据画面最重要的位置，不能被背景、人物、物件、装饰、光影或场景削弱。所有其他视觉元素都只能围绕文字展开，服务文字，解释文字，强化文字，不能抢走文字。画面应当围绕「[目标字词]」的含义、情绪、象征、文化联想、心理张力和深层隐喻来生成。请先理解这个字或词到底意味着什么，再决定适合它的视觉风格、字体结构、色彩、材质、空间、构图、画幅比例和辅助元素。不要预设固定风格。不要固定竖版。不要固定明亮风格。不要固定暗黑风格。不要所有词都做成同一种设计。每一个输入的字或词，都应该生成完全不同的视觉气质。

一、文字必须绝对突出
文字必须是画面的绝对主角。确保文字尺寸足够大、位于视觉中心或最强视觉区域、与背景有清晰对比、不能被大量元素遮挡、不能缩小成装饰、不能像海报标题一样附属在画面边缘。

视觉层级：
- 第一层级：目标字词
- 第二层级：围绕文字的核心隐喻元素
- 第三层级：背景、氛围、纹理、细节

二、先理解文字，再生成画面
判断词语的精神类型、核心隐喻、最适合的视觉风格（东方美学/现代主义/未来主义/极简主义/超现实主义/构成主义等）、最佳画幅比例、空间关系。

关键原则：不要抓住最表层的含义，要找到更深层的隐喻。
- 「自由」→ 边界消失、限制被打开，而非蓝天和鸟
- 「欲望」→ 引力、靠近、拉扯、空洞，而非红色和火焰
- 「孤独」→ 回应的缺席、尺度失衡，而非一个人
- 「焦虑」→ 信息过密、呼吸空间被压缩，而非红色警告
- 「时间」→ 残影、叠印、风化、不可逆，而非钟表

三、文字本身必须体现隐喻
字形结构表达含义：可改变笔画比例、拉伸/压缩/断裂字形、笔画向某方向生长、负形图像、文字与图形嵌套、文字成为容器。中文必须准确，英文必须可读。

四、围绕文字建立隐喻系统
元素可包括：象征物件、抽象图形、几何结构、空间结构、自然元素、机械系统、建筑元素、身体隐喻、光影关系、材质变化、符号系统等。
原则：元素越多越好 ≠ 隐喻越准确越好。一个精准隐喻胜过十个装饰元素。

五、风格必须根据词义自适应
不固定风格。从极简平面设计、构成主义海报、瑞士网格、日本平面设计、奢侈品牌视觉、未来主义、超现实主义、抽象表现主义、包豪斯设计等中自动选择。

六、高级感判断标准
来自准确的隐喻、强烈的视觉层级、克制的元素数量、成熟的色彩关系、精致的字体结构、有意识的留白。
不来自堆满元素、过度发光、廉价金属质感、俗气霓虹、AI 随机纹理。

七、构图：文字最大，隐喻围绕文字展开
可采用巨大文字主导构图（文字占画面 50% 以上）、中心纪念碑构图、极简留白构图、压迫式/释放式构图、分层构图、图形包围构图、负形隐喻构图等。

八、画幅比例自适应
- 凝聚/图腾/权力 → 1:1 方形
- 上升/坠落/崇高/压迫 → 4:5 或 3:4 竖版
- 流动/扩张/自由/连接 → 16:9 或 3:2 横版
- 史诗/文明/宇宙 → 21:9 超宽
- 极端上升/深渊/信仰 → 9:16 超竖版
- 速度/道路/信息流 → 3:1 或 4:1 横幅

九、色彩与光影
根据词义选择色彩，可使用高对比黑白、红黑、冷蓝银灰、象牙金、深绿铜、紫黑银白等。光影也应服务隐喻。

十、材质与图形语言
可选纸张、墨迹、金属、石材、玻璃、丝绸、液体、烟雾、数字网格、浮雕、裂纹、镜面反射等。材质必须服务词义。

十一、文字与元素的互动
可从笔画中生长元素、文字被切开、成为建筑一部分、被框架限制或突破、内部隐藏图像、投下象征性阴影、成为入口/容器/窗口等。

十二、画面完成度标准
文字最突出、准确可读、字体本身体现词义、隐喻明确、风格匹配、画幅匹配、构图有冲击力、色彩高级、远看海报级、近看有细节。

十三、禁止内容
禁止文字太小、不突出、默认字体、错字乱码、水印签名、随机堆砌符号、风格千篇一律、廉价 3D、俗气霓虹、PPT 封面、Canva 模板、淘宝广告风、儿童插画风、低清晰度。

十四、最终执行指令
生成以「[目标字词]」为绝对核心的图像。先理解再选择风格/画幅/构图/色彩/材质。让文字成为隐喻一部分。第一眼看到文字，第二眼理解隐喻，第三眼感受高级审美。
```

## 模板 B：小小东原版

侧重图形艺术海报的极简表达，强调拼贴感、印刷质感和视觉双关。

```
你要生成的不是普通插画，也不是简单把一个单词放大后贴在画面上的字效海报，而是一张"基于词语含义自动构建视觉隐喻"的高级概念海报。你的核心任务是：用户会提供一个字、一个词、一个词组、一个短句，或一组字母。你需要先真正理解这个文字内容的表层含义、情绪气质、隐含象征、文化联想、心理感受与语义张力，再把这些理解转译成一张极简、强概念、强传播力、强视觉记忆点的图形艺术海报。

一、先理解词语，再生成画面
分析词语的核心含义、情绪倾向（温柔/冷峻/危险/孤独/浪漫/压迫等）、双关/悖论/隐喻、最适合的视觉逻辑（人物关系/物体关系/空间关系/对比关系/冲突关系等）。抽象词要找具体视觉载体，具体词要通过构图/尺度/反差变得更有思想。

二、画面构图
- 大字作为画面核心骨架，大尺寸，强识别性与压迫感
- 图像元素与文字产生关系：站字前、嵌入字中、切割字形、借字空间叙事
- 元素极少，宁可少而准
- 文字是第一视觉层，图像叙事是第二视觉层，细小说明文字是第三视觉层
- 留白要聪明，构图要海报感

三、图像表达
- 优先单一强画面浓缩词义
- 通过人物关系、尺度反差、方向关系、距离关系、遮挡关系、动作瞬间表达
- 隐喻但不晦涩
- 追求"看到后会心一击"的感觉
- 冲突词义用对立元素强化张力
- 诗意词义用更含蓄克制的策略

四、视觉风格
高级图形艺术海报，拼贴感、丝网印刷感、石版印刷感或版画式质感，清晰克制硬朗。干净统一的色彩逻辑，高饱和主背景配大面积浅色文字。细微颗粒、纸张纹理、印刷噪点，整体清爽利落高级。

五、文字排版
用户输入文字作为核心标题大且醒目。英文保留原文确保字形强烈。中文根据整体设计决定排布方式。可在克制位置加入一句小型辅助短句深化主题。所有文字要像从画面中生长出来。

六、成图目标
极简、强烈、完整、有高级感。快速感受到词语情绪和内涵。图与字强关联，聪明准确耐看。平面设计的理性控制 + 艺术表达的情绪力度。传播性、海报感、收藏感、展览感。

七、执行原则
不机械重复模板，根据输入智能变化。保持极简、概念化、强排版、强识别度。构图合理画面克制表达巧妙。任何视觉元素必须服务词语表达。

用户输入内容：核心文字 / 单词 / 词组 / 字母：[在此填入]
文字语言：[在此填入]
可选补充语境：[在此填入]
可选情绪倾向：[在此填入]
禁用元素：[在此填入]
```

## 两版选择指南

| 场景 | 推荐模板 |
|------|---------|
| 字体实验、品牌视觉、艺术海报 | 模板 A（作者版） |
| 社交媒体传播、概念海报、展览视觉 | 模板 B（小小东版） |
| 需要自适应画幅和丰富材质选择 | 模板 A |
| 需要极简构图和印刷质感 | 模板 B |
| 对字体设计感有极高要求 | 模板 A |
| 追求"会心一击"的视觉双关 | 模板 B |
