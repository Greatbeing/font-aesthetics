# 自指进化引擎

## 核心逻辑

每一次「生成 → 反馈 → 修正」构成一个迭代循环。系统不依赖外部训练，而是在对话中逐步收敛到用户审美最优解。

```
生成图像 → 收集反馈 → 问题诊断 → 自指优化 → 下一轮生成
    ↑                                                    │
    └────────── 偏好积累 · 长期记忆 ─────────────────────┘
```

---

## 一、反馈收集框架

### 三级评估量表

每次生成后，从以下三个维度中选择 1-2 个最关键的点收集反馈：

#### 隐喻准确度（1-5）

| 评分 | 标准 | 用户典型表述 |
|------|------|-------------|
| 1 | 完全停留在表面联想 | "这不就是字面意思吗" |
| 2 | 有尝试隐喻，但方向偏差 | "感觉还是不太对" |
| 3 | 隐喻基本准确，但不够深刻 | "还行，但没有惊喜" |
| 4 | 隐喻准确且有深度 | "这个角度不错" |
| 5 | 隐喻精准深刻，令人会心一击 | "就是这个感觉！" |

#### 风格匹配度（1-5）

| 评分 | 标准 | 用户典型表述 |
|------|------|-------------|
| 1 | 风格与词义严重冲突 | "这个词不应该长这样" |
| 2 | 风格大致正确但不精致 | "方向对，但质感不好" |
| 3 | 风格匹配，无明显问题 | "风格可以接受" |
| 4 | 风格与词义高度契合 | "风格选得好" |
| 5 | 风格完美，无替代方案 | "就是这个风格" |

#### 审美满意度（1-5）

| 评分 | 标准 | 用户典型表述 |
|------|------|-------------|
| 1 | 需要完全重做 | "重新来吧" |
| 2 | 方向需要大改 | "改一下风格/构图" |
| 3 | 微调即可 | "色调调一下就好" |
| 4 | 基本满意，小细节可优化 | "不错的，色彩再亮一点" |
| 5 | 超出预期，无需修改 | "完美！" |

### 反馈收集技巧

- **单次只问 1-2 个维度**，避免用户疲劳
- **优先问不满意的维度**："如果只有一个地方可以改进，是什么？"
- **对满意部分记录但不追问**，作为偏好积累
- **模糊反馈追问具体信号**："太平淡" → "是构图不够大胆，还是色彩不够有张力？"

## 二、问题诊断决策树

```
用户说"不满意"
  ├── 能明确指出问题 → 直接匹配修正方向
  │   ├── "构图不行" → 更换构图类型
  │   ├── "颜色不对" → 调整色彩系统
  │   ├── "字体不好" → 重新设计字体
  │   └── "隐喻不对" → 重新语义分析
  │
  └── 不能明确指出 → 按概率诊断
      ├── 60% 隐喻问题（根本性偏离）
      ├── 25% 风格匹配问题
      └── 15% 执行细节问题（色彩/尺寸/元素）
```

### 问题信号 → 根因映射

| 信号 | 根因优先级 | 修正策略 | 代价 |
|------|-----------|----------|------|
| "不够震撼" | 构图保守 > 色彩弱 > 字体普通 | 增大文字占比，强化对比 | 低 |
| "看不出和词义的关系" | 隐喻停留在表层 | 重做 Step 1 语义分析 | 高 |
| "风格不对" | 情绪-风格映射错误 | 重新判断情绪类型并换风格 | 中 |
| "太复杂/太乱" | 元素过多，层级崩塌 | 削减到核心 1-2 个元素 | 低 |
| "太简单/太空" | 留白过度，缺少锚点 | 增加 1 个精准隐喻元素 | 低 |
| "太暗/太亮" | 色彩系统偏离词义 | 调整明度或更换色系 | 低 |
| "字体不好看" | 设计感与可读性失衡 | 重新平衡字体设计 | 中 |
| "像模板" | 风格自适应失败 | 从完全不同风格体系切入 | 中 |
| **"多字了"** | **文字约束缺失** | **加入文字清单声明 + 禁止指令，重申"只出现以下文字"** | **低** |
| **"少字了"** | **文字锚定不足** | **在提示词中重复目标文字 3 次，结尾重申** | **低** |
| **"有错字/乱码"** | **模型文字能力不足** | **缩短文字至 ≤4 字，或拆分为多张图** | **中** |

## 三、三级迭代策略

### Level 1: 轻调（用户评分 3-4 / 审美满意度 3）

保留当前方案骨架，局部调整：

```
保留：语义理解结果、构图类型、画幅比例
调整：
  - 色彩：微调色相/饱和度/明度 ±15%
  - 文字：缩放 ±10%，位移调整
  - 元素：替换或微调 1 个辅助元素的排列方式
  - 氛围：增强或减弱纹理/颗粒/光影强度
重新生成数量：1 版
```

### Level 2: 重构（用户评分 2 / 审美满意度 2）

保留语义分析结果，更换视觉策略：

```
保留：核心隐喻、情绪判断、空间倾向
更换：
  - 构图类型（如极简留白 → 压迫式构图）
  - 色彩系统（如冷蓝银灰 → 红黑）
  - 画幅比例（如竖版 → 方形）
  - 视觉风格（如构成主义 → 超现实主义）
重新生成数量：2-3 版供对比选择
```

### Level 3: 推翻（用户评分 1 / 审美满意度 1）

从 Step 1 重新开始：

```
动作：
  1. 回到语义分析，换一个切入角度重新理解词义
  2. 参考隐喻映射表寻找替代隐喻方向
  3. 尝试完全不同的视觉语言体系
  4. 输出 3 个完全不同的方案草图供用户选择方向
重新生成数量：3 版对比方案
```

### 迭代上限

| 指标 | 上限 | 超出后行为 |
|------|------|-----------|
| 同词迭代次数 | 3 轮 | 暂停，建议用户提供参考图或描述期望风格 |
| 同类问题反复出现 | 2 次 | 标记为系统盲区，记录并降级处理 |
| 单轮耗时 | 不适用 | 每次迭代后主动询问是否继续优化 |

## 四、偏好学习机制

### 积累维度

每次成功产出后，自动更新以下偏好档案：

```json
{
  "user_profile": {
    "style_preferences": {
      "极简主义": { "count": 5, "avg_rating": 4.6, "weight": 0.35 },
      "构成主义": { "count": 2, "avg_rating": 3.5, "weight": 0.10 },
      "东方书法": { "count": 3, "avg_rating": 4.3, "weight": 0.25 }
    },
    "color_preferences": {
      "深色系": { "count": 6, "avg_rating": 4.5, "weight": 0.40 },
      "暖色系": { "count": 3, "avg_rating": 3.7, "weight": 0.15 },
      "黑白": { "count": 4, "avg_rating": 4.8, "weight": 0.30 }
    },
    "aspect_preferences": {
      "3:4 竖版": { "count": 5, "avg_rating": 4.4, "weight": 0.40 },
      "1:1 方形": { "count": 3, "avg_rating": 4.0, "weight": 0.25 }
    },
    "complexity_preference": "极度克制",
    "word_categories": ["情绪类", "概念类", "哲学类"],
    "success_cases": [
      { "word": "孤独", "style": "极简留白", "rating": 5 },
      { "word": "自由", "style": "构成主义", "rating": 4 }
    ]
  }
}
```

### 应用策略

- **新词生成时**：优先采用权重最高的偏好方向作为默认起点
- **风格决策冲突时**：偏好档案权重打破僵局
- **连续 3 次获得 4+ 评分的风格**：自动升级为「强偏好」，后续优先使用
- **连续 2 次获得 ≤2 评分的风格**：降权，避免重复

### 偏好衰减

为避免过度固化，引入时间衰减因子：

```
权重 = 原始权重 × e^(-0.05 × 距上次使用天数)
```

长期未使用的风格偏好缓慢降低权重，保持探索空间。

## 六、进化停滞检测

当以下信号出现时，触发主动进化干预：

| 信号 | 阈值 | 干预方式 |
|------|------|----------|
| 连续 N 次使用同一风格 | N ≥ 5 | 提示用户尝试新风格方向 |
| 审美满意度连续下降 | 连续 2 次 | 主动询问"要不要换一种风格试试？" |
| 用户始终不给出负面反馈 | N ≥ 5 | "有没有哪种风格你一直想尝试？" |
| 同类词反复生成 | N ≥ 4 | 建议探索新的词类方向 |
