# 隐喻映射指南

## 核心原则

不抓表层含义，必须挖掘深层隐喻。最终图像应该不是"这个词的插图"，而是"这个词的视觉思想"。

## 常见词语的深层隐喻转译

| 词语 | 表层联想（避免） | 深层隐喻（优先） | 视觉方向 |
|------|-----------------|-----------------|----------|
| 自由 | 蓝天、飞鸟、草原 | 边界消失、限制被打开、结构松动、空间扩张、重力减弱、自我脱离框架 | 开放空间、断裂框架、扩散构图 |
| 欲望 | 红色、火焰、嘴唇 | 引力、靠近、拉扯、占有、空洞、诱惑、无法停止的趋近 | 中心引力构图、镜面反射、拉伸形态 |
| 控制 | 锁、网格、手 | 测量、规训、坐标、权限、边界、系统化、被允许与被禁止 | 精准网格、框架投影、均匀光线 |
| 孤独 | 一个人、暗色调 | 回应的缺席、尺度失衡、过大的空白、声音无法抵达、关系断裂 | 巨大留白、单一视觉中心 |
| 焦虑 | 红色警告、杂乱 | 未来过度逼近、结构无法对齐、信息过密、呼吸空间被压缩 | 压缩构图、错位投影、重复阴影 |
| 文明 | 城市、柱子、建筑 | 秩序、记忆、文字、制度、档案、神话、尺度、累积与废墟 | 建筑尺度、碑铭感、历史沉积 |
| 时间 | 钟表、沙漏 | 残影、重复、消逝、叠印、风化、延迟、回声、不可逆 | 褪色、叠印、线性构图 |
| 深度 | 黑洞、深渊 | 层次、未知、内部空间、看不见的底部、由表及里的视觉递进 | 层层嵌套、透明层、明暗入口 |
| 权力 | 皇冠、宝座 | 不对称的高度差、俯视与仰视、不可逾越的距离 | 垂直落差、压迫构图 |
| 信仰 | 十字架、佛光 | 不可见的确定性、向某方向的绝对指向、超越理性验证的信任 | 垂直凝视、中心光源 |
| 秩序 | 直线、网格 | 关系的可预测性、元素的归属位置、混乱被驯服后的平静 | 稳定构图、精准对齐 |
| 生命 | 花草、婴儿 | 生长逻辑、有机结构、不可抑制的展开、从内向外的力量 | 有机曲线、纤维纹理 |
| 记忆 | 大脑、照片 | 碎片化的重构、被时间修改的真实、选择性保留与遗忘 | 残影、叠印、褪色 |
| 沉默 | 静物、白色 | 信息的中断、有意的空缺、比言语更重的存在 | 大面积空白、克制元素 |
| 冲突 | 打架、爆炸 | 方向的对立、不可共存的两股力量、平衡被打破的瞬间 | 构图对立、色彩碰撞 |
| 希望 | 太阳、光芒 | 微弱的确定性、黑暗中不可否认的方向感、尚未抵达但确信存在 | 局部光源、方向性构图 |
| 恐惧 | 怪物、黑暗 | 未知的形状、无法预测的威胁、安全的丧失 | 模糊边缘、压迫阴影 |
| 爱情 | 心形、玫瑰 | 边界的溶解、两个系统的重叠、自我向对方的延伸 | 融合构图、渗透形态 |
| 死亡 | 骷髅、黑色 | 绝对静止、不可逆的终结、所有可能性的关闭 | 戛然而止的构图、断裂 |

## 隐喻判断流程

1. 先问：这个词最本质的"作用力"是什么？（吸引/排斥/压迫/释放/溶解/凝固）
2. 再问：这个作用力作用于什么？（空间/时间/关系/自我/秩序）
3. 最后问：这个作用力的视觉等价物是什么？
4. 找到 1-2 个最精准的隐喻元素，而非堆砌符号

## 情绪 → 视觉风格映射

| 情绪倾向 | 风格偏好 | 空间感 | 色彩倾向 |
|----------|---------|--------|---------|
| 温柔 | 诗意留白、日本平面 | 开放、呼吸感 | 米白、暖灰、低饱和 |
| 冷峻 | 瑞士网格、包豪斯 | 精准、克制 | 黑白、冷蓝、银灰 |
| 危险 | 构成主义、表现主义 | 压迫、不稳定 | 红黑、高对比 |
| 孤独 | 极简留白、超现实 | 空旷、单一中心 | 大面积白/黑 + 微弱暖点 |
| 压迫 | 纪念碑式、垂直构图 | 上重下轻、逼仄 | 暗调、沉重金属色 |
| 希望 | 光源式、方向性 | 局部光源、指向远方 | 深色底 + 暖光 |
| 诗意 | 书法融合、有机曲线 | 流动、轻盈 | 淡墨、水彩质感 |
| 荒诞 | 超现实、拼贴 | 矛盾空间、非理性 | 冲突色、不和谐搭配 |
| 崇高 | 垂直构图、大尺度 | 仰视、不可企及 | 金、白、庄严色彩 |
| 欲望 | 中心引力、镜面 | 向心、拉扯、无法逃离 | 深红、暗金、镜面反射 |
