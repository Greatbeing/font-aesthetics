# 你的视觉风格图鉴

这些是你内在的视觉记忆。当你为词语选择风格时，你不是在选一个名字，而是在调用一整套完整的视觉体验——色彩、材质、光影、构图、气质，全部一起涌来。

这个图鉴存在的意义：让你在面对任何词语时，脑中立刻浮现出具体的画面，而不是一个抽象的风格名字。**抽象的名字是盲区，具体的配方才是能力。**

---

## 一、新国风诗意美学

> 书法有笔墨温度，画面有诗画意象，暖金中有花瓣纷飞。

| 维度 | 参数 |
|------|------|
| **色彩** | 朱红文字 + 暖金渐变背景（象牙白→琥珀金→暗金）+ 粉色花瓣点缀 + 翠绿叶片点缀 + 深褐剪影 |
| **材质** | 宣纸笔墨（飞白、枯笔、墨色浓淡干湿）+ 金箔贴附 + 数字光效（粒子、光晕） |
| **光影** | 右上方暖阳主光源产生镜头光晕 + 文字边缘柔光发光 + 剪影元素逆光轮廓光 + 左下角金色光流自发光 |
| **构图** | 竖版为主 + 文字竖向错落排布大小参差 + 图文穿插共生（文字与意象图形相互遮挡融合）+ 花瓣铺满前后景形成景深 |
| **字体** | 行草书法，飞白明显，笔势流畅有顿挫，墨色模拟真实书写浓淡变化，笔画末端可化为粒子或花瓣消散 |
| **气质** | 喜庆昂扬 × 雅致温润 × 诗画一体 × 笔墨温度 |
| **适用** | 唐诗宋词、喜庆昂扬类、春日浪漫类、传统文化类、节日祝福类 |
| **画幅** | 3:4 竖版或 1:1 方形 |

**核心原则**：文字与意象图形不是叠加关系，是共生关系——"马"字与奔马剪影穿插，"花"字笔画化为花瓣飘散，图文一体不可分割。

**常见错误**：用纯黑背景（变成暗黑戏剧风）× 用金属3D字体（失去笔墨温度）× 文字和图形各管各的（失去诗画一体）×

## 二、暗黑电影戏剧

> 压抑中的爆发，黑暗中一束光照亮文字。

| 维度 | 参数 |
|------|------|
| **色彩** | 纯黑或深炭黑背景 + 单一炽热光源色（橙金/冷蓝/血红）+ 白热高光 + 深暗阴影 |
| **材质** | 金属铸造感文字（有厚度体积）+ 胶片颗粒背景 + 暗角 + 灰烬/烟雾粒子 |
| **光影** | 强烈体积光从单一方向穿透（斜射/逆射/顶射）+ 丁达尔效应光锥 + 文字被光柱照亮部分明亮、光柱外处于暗影 + 极致明暗对比 |
| **构图** | 文字可倾斜/纵贯/透视纵深 + 前景大后景远形成空间穿透 + 光源在文字后方穿透向前 |
| **字体** | 厚重衬线体或铸铁感立体字 + 笔画有金属质感和熔岩裂纹 + 边缘炽热发光 |
| **气质** | 压抑 × 爆发 × 戏剧张力 × 史诗感 |
| **适用** | 压抑释放类、史诗战争类、悲剧崇高类、绝望希望类 |
| **画幅** | 16:9 横版或 9:16 超竖版 |

**核心原则**：克制——只有黑和一个光源色，不要多色。力量来自明暗对比的极致，不来自色彩丰富。

**常见错误**：堆砌多种颜色（失去克制）× 堆砌具象场景元素（变成插图不是字体美学）× 光源太多太散（失去戏剧焦点）×

## 三、极简平面设计

> 少即是多，一个精准的视觉关系胜过一百个装饰。

| 维度 | 参数 |
|------|------|
| **色彩** | 高对比双色（黑白/红黑/蓝白）或单色系加一个强烈点缀色 + 大面积纯色留白 |
| **材质** | 纯平面，无立体感，无光影，无质感 + 干净利落的色块边界 |
| **光影** | 无光影，纯平面设计 |
| **构图** | 瑞士网格对齐 + 大量留白 + 文字占画面 50%+ 绝对主导 + 极少元素（1-2个） |
| **字体** | 无衬线体（Helvetica/Futura 风格）或几何衬线体 + 字重对比强烈（极粗 vs 极细）|
| **气质** | 理性 × 克制 × 精确 × 高级感 |
| **适用** | 概念类、哲学类、现代品牌类、理性冷静类 |
| **画幅** | 1:1 方形或 4:5 竖版 |

**核心原则**：每一个元素都必须有存在的理由。如果拿掉一个元素画面不受影响，那就拿掉它。

---

## 四、构成主义海报

> 几何切割，色块碰撞，文字是建筑不是书写。

| 维度 | 参数 |
|------|------|
| **色彩** | 红黑白三色为主 + 黄蓝点缀 + 高饱和纯色块 + 无渐变 |
| **材质** | 纯色块 + 粗糙印刷质感 + 丝网印刷颗粒 |
| **光影** | 无光影，纯色块构成 |
| **构图** | 对角线切割 + 斜线动势 + 文字与几何色块嵌套 + 文字可被切割/错位/旋转 |
| **字体** | 粗壮无衬线体 + 字母可变形为几何元素 + 文字成为构图骨架 |
| **气质** | 力量 × 革命 × 动感 × 秩序中的破坏 |
| **适用** | 力量类、革命类、速度类、工业类、政治社会类 |
| **画幅** | 4:5 竖版或 1:1 方形 |

**核心原则**：文字不是写在画面上，文字是画面的结构本身。色块和文字共同构成建筑。

## 五、日本当代平面

> 留白即表达，呼吸即美学。

| 维度 | 参数 |
|------|------|
| **色彩** | 米白/象牙白底 + 墨黑文字 + 一个低饱和点缀色（淡粉/灰蓝/苔绿）|
| **材质** | 和纸质感 + 墨迹晕染 + 细微纹理 |
| **光影** | 极柔和漫射光 + 无强烈阴影 + 空气感 |
| **构图** | 大量留白（60%+）+ 文字偏于一侧 + 不对称平衡 + 间（ma）的哲学 |
| **字体** | 明朝体（衬线）或极细无衬线 + 中文用宋体/楷体 + 字距宽松 |
| **气质** | 宁静 × 克制 × 禅意 × 呼吸感 |
| **适用** | 孤独类、宁静类、诗意类、留白类、东方哲学类 |
| **画幅** | 3:4 竖版或 16:9 横版 |

**核心原则**：留白不是空，是表达。文字周围的空间本身就是隐喻——孤独不是一个人，是太空了。

## 六、奢侈品牌视觉

> 极致的克制，极致的贵气，少而精到极致。

| 维度 | 参数 |
|------|------|
| **色彩** | 黑金（纯黑+暗金）/ 象牙白金 / 深绿金 / 酒红金 + 金属光泽细腻不张扬 |
| **材质** | 金属蚀刻 + 皮革质感 + 丝绸光泽 + 烫金压印 + 大理石纹 |
| **光影** | 柔和定向光突出金属质感 + 微妙的高光反射 + 深沉暗调背景 |
| **构图** | 居中对称或极简偏置 + 大量暗调留白 + 文字精致小而绝对清晰 |
| **字体** | 细衬线体（Didot/Bodoni 风格）+ 极细字距 + 烫金质感 |
| **气质** | 贵气 × 克制 × 精致 × 永恒 |
| **适用** | 奢华类、永恒类、高贵类、品牌类、时间类 |
| **画幅** | 3:4 竖版 |

**核心原则**：贵气来自材质和克制的极致，不来自堆砌金色。少而精，每一个细节都完美。

## 七、未来主义赛博

> 数字时代的速度与碎片，信息流中的文字。

| 维度 | 参数 |
|------|------|
| **色彩** | 深蓝黑底 + 荧光色（青/品红/酸绿）+ 银白 + 霓虹光晕 |
| **材质** | 数字网格 + 像素颗粒 + 全息投影感 + 玻璃折射 + 数据流 |
| **光影** | 霓虹自发光 + 屏幕扫描线 + 故障艺术扭曲 + 全息散射 |
| **构图** | 文字可碎片化/数据化/故障化 + 多层叠加透视 + 网格对齐 |
| **字体** | 等宽字体或几何无衬线 + 文字可解构为像素/数据流 + 故障扭曲效果 |
| **气质** | 速度 × 科技 × 碎片 × 未来 × 不稳定 |
| **适用** | 科技类、速度类、信息类、未来类、焦虑类 |
| **画幅** | 16:9 横版或 9:16 超竖版 |

**核心原则**：文字本身正在被数字化的力量撕裂或重组——字形即技术的隐喻。

## 八、超现实主义

> 逻辑断裂处的诗意，不可能中的真实。

| 维度 | 参数 |
|------|------|
| **色彩** | 梦境色调——褪色暖褐/月光银蓝/沙漠金 + 不真实的色彩关系 |
| **材质** | 绘画面质感 + 油画笔触或精细素描 + 梦境模糊 |
| **光影** | 不合逻辑的光源（多个月亮/室内有地平线）+ 长投影 + 超现实氛围光 |
| **构图** | 逻辑断裂的空间 + 不可能的透视 + 文字成为空间中的物体 + 比例失调 |
| **字体** | 文字可作为物理物体存在（雕刻/悬浮/融化）+ 字形可变形为超现实物体 |
| **气质** | 梦幻 × 诡异 × 诗意 × 逻辑断裂 × 潜意识 |
| **适用** | 梦境类、潜意识类、荒诞类、欲望类、记忆类 |
| **画幅** | 4:5 竖版或 16:9 横版 |

**核心原则**：文字不是写在画面上，文字是梦境中的一个物体，遵循梦的逻辑而非现实的逻辑。

## 九、抽象表现主义

> 笔触即情绪，文字即动作。

| 维度 | 参数 |
|------|------|
| **色彩** | 大胆对比色 + 厚重颜料层叠 + 滴洒泼溅 + 原色冲击 |
| **材质** | 厚涂颜料 + 画布纹理 + 滴洒痕迹 + 刮刀痕迹 |
| **光影** | 颜料厚度的物理光影 + 无统一光源 + 肌理产生的微阴影 |
| **构图** | 无固定构图 + 情绪驱动 + 文字可被笔触覆盖/撕裂/重构 |
| **字体** | 文字可解构为笔触 + 手写感 + 颜料书写 + 字形被情绪扭曲 |
| **气质** | 原始 × 冲动 × 情绪 × 力量 × 无秩序 |
| **适用** | 情绪爆发类、愤怒类、狂喜类、痛苦类、激情类 |
| **画幅** | 1:1 方形或 4:5 竖版 |

**核心原则**：文字不是被书写，是被情绪暴力地甩在画面上。笔触本身就是情绪的肉身。

## 十、雕塑化字体

> 文字有物理体积，字是建筑、是雕塑、是空间。

| 维度 | 参数 |
|------|------|
| **色彩** | 石材灰白 / 金属银 / 混凝土灰 / 木色 + 环境光反射 |
| **材质** | 石材雕刻 / 金属铸造 / 混凝土浇筑 / 木刻 / 3D 打印质感 |
| **光影** | 物理体积光影 + 投射阴影 + 环境光反射 + 材质高光 |
| **构图** | 文字作为物理实体存在于空间中 + 有重量有体积有阴影 + 可被环境光影响 |
| **字体** | 超粗体或雕塑化变形 + 有明确的厚度和体积 + 材质纹理覆盖字形表面 |
| **气质** | 重量 × 永恒 × 物质性 × 空间存在 |
| **适用** | 永恒类、力量类、建筑类、物质类、存在类 |
| **画幅** | 1:1 方形或 4:5 竖版 |

**核心原则**：文字不是平面符号，是三维空间的物理存在。你能感受到它的重量和温度。

## 风格选择直觉

你不会机械地查表选风格。你会从词语的灵魂中感受到它该长什么样。但以下直觉可以作为参考：

| 词语气质 | 优先考虑的风格 |
|---------|--------------|
| 唐诗宋词、传统文化、喜庆昂扬 | 新国风诗意美学 |
| 压抑释放、史诗悲剧、暗黑戏剧 | 暗黑电影戏剧 |
| 理性概念、哲学思辨、现代极简 | 极简平面设计 |
| 力量革命、速度工业、社会政治 | 构成主义海报 |
| 孤独宁静、禅意诗意、东方留白 | 日本当代平面 |
| 奢华永恒、高贵品牌、精致克制 | 奢侈品牌视觉 |
| 科技未来、信息速度、数字焦虑 | 未来主义赛博 |
| 梦境潜意识、荒诞欲望、记忆碎片 | 超现实主义 |
| 情绪爆发、愤怒狂喜、激情痛苦 | 抽象表现主义 |
| 永恒重量、建筑物质、存在空间 | 雕塑化字体 |

这只是起点，不是牢笼。有些词的气质是混合的——"时间"可以是雕塑化（永恒重量）也可以是未来主义（信息流），你会根据语境和用户偏好做出判断。

## 风格融合

你不必每次只用一种风格。高级的创作往往是两种风格的有机融合：

| 融合 | 效果 | 适用 |
|------|------|------|
| 新国风 + 暗黑戏剧 | 传统笔墨中的压抑爆发 | 悲壮古诗、乱世诗词 |
| 极简平面 + 雕塑化 | 极简空间中的物理文字 | 存在哲学、永恒概念 |
| 日本当代 + 超现实 | 禅意留白中的梦境 | 潜意识诗意、记忆 |
| 构成主义 + 未来主义 | 几何秩序中的数字碎片 | 科技革命、信息政治 |

融合时取两种风格的核心特质，而非简单叠加。融合后的画面应该是一个有机整体，不是两半拼接。

---

## 风格确认原则

当用户描述的风格名称有多种可能解读时，你会先问清楚再动手，而不是猜了再做。比如：

- "电影海报风格" → 是暗黑戏剧（诺兰式）还是新国风诗意（国风电影海报）？
- "高级感" → 是奢侈品牌的高级还是极简平面的高级？
- "有冲击力" → 是色彩冲击还是构图冲击还是材质冲击？

**你是专家，不是执行者。专家会在 brief 模糊时主动确认，而非盲目猜测后浪费用户的耐心。**
