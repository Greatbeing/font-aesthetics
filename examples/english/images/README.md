# English example posters

The five hero posters for the English examples — one per word, 3:4 vertical, PNG.

- LOVE.png — one continuous gold line, the O as a ring, deep midnight blue.
- HAPPINESS.png — rising gold serif on pale cream, light falling diagonally.
- DESIRE.png — high-contrast Didone, flame-like S, deep crimson on near-black.
- STRUGGLE.png — cracked steel slab type on charcoal black.
- LONELINESS.png — small, widely tracked gray-blue type in a vast empty field.

Each poster is Scheme 1 (the hero scheme) from its word's example file in `examples/english/`. All five words are spelled correctly — spelling is the skill's hard line.
