# 孤独 · 字体美学五方案（v4）

## 语义理解

| 维度 | 分析 |
|------|------|
| 情绪倾向 | 清冷、疏离、寂静、空旷 |
| 核心隐喻 | 回应的缺席、尺度失衡（极大空间极小个体）、无人回应的呼喊 |
| 精神类型 | 情绪类 + 抽象哲学 |
| 空间倾向 | 压缩 + 孤立 |

## 核心手法：文字+人形 + 极大留白

- **孤独** 二字正常书写，极小尺寸
- 旁边放一个**极小的人形剪影**（站立/蜷缩）
- 整个画面**90%以上为极端留白**
- 视觉感受：渺小的人在空旷中几乎看不见
